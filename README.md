# Mitt första projekt

Luffarschack (tre i rad) mellan John (grön) och Vera (lila), bäst av 5 matcher.
Variant: "rullande brickor" — varje spelare får max ha 3 brickor på brädet, den äldsta
försvinner automatiskt när en fjärde läggs, så brädet aldrig blir fullt.

## Starta spelet

```bash
npm start
```

Öppna sedan `http://localhost:3000` i webbläsaren.
