# Mitt första projekt

Luffarschack (tre i rad) mellan John (grön) och Vera (magenta), bäst av 5 matcher, i en retro
80/90-tals rymdstil (pixelfont, blinkande stjärnhimmel, neonramar).

Vem som börjar match 1 slumpas, sen börjar alltid **förloraren** av föregående match nästa. Ingen
match kan sluta oavgjort: när en spelare har 3 brickor ute får de inte längre placera nya — de måste
istället **dra** en av sina egna brickor till en tom ruta (går att dra fysiskt, eller trycka på
brickan och sen på destinationen). Vinner man ritas ett streck genom de tre vinnande brickorna direkt
på brädet.

## Starta spelet

```bash
npm start
```

Öppna sedan `http://localhost:3000` i webbläsaren.

## Spela på telefonen

fungerar även offline efter första besöket.
